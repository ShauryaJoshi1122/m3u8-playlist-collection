# Complete M3U Playlist Link Directory

Copy any URL below into a player that supports M3U/M3U8 playlist URLs.

These are **playlist index URLs** from the public [iptv-org/iptv project](https://github.com/iptv-org/iptv). They are not individual channel stream URLs. Each playlist may contain many channels, and the channel list can change upstream.

## Important notes

- This directory lists the 12 playlist pointers currently maintained in this repository.
- These are **not** a complete channel-by-channel inventory. To list every channel by its actual name and direct stream URL, the upstream M3U files must be parsed and checked separately.
- Channel availability, names, and stream URLs are controlled by the upstream project and may change.
- Only use streams where you have permission and where the provider's terms and applicable law allow it.
- The third-party Gist reviewed for this repository was not imported because it did not establish redistribution or rebroadcast permission for its endpoints.
